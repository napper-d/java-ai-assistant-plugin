## 2. R1：配置与项目级服务组装

### 工作

1. 新增项目级 RAG 配置：Embedding 协议、基础地址和模型；高级参数包括请求时限、维度、分块/重叠、批量大小、相关性阈值、PPTX 备注、输入前缀和多步检索预算。
2. 通过 IDEA Settings > Tools > Course AI Assistant > Course RAG 提供配置入口。普通参数保存在项目本地 workspace 状态；API Key 仅通过 PasswordSafe 保存，不进入项目配置、日志或索引。
3. 密钥输入框不回填已保存的密钥；留空保留原密钥，提供明确的清除选项。PasswordSafe 访问在后台执行，保存失败需反馈，不能静默当成成功。
4. 直接构造 `RagConfig`，不自动读取 `.env` 或进程环境变量。首版支持现有 `openai-compatible` 协议，不默认填写远端地址或模型。
5. 新增 `ProjectRagService`：按需创建并拥有 CourseIndexer、LocalKnowledgeSearch 和共享的惰性 Embedding 客户端。登记资料不创建 HTTP 客户端或读取密钥。
6. 保存改变后的配置时使旧服务失效并取消其在途任务；之后按新配置重建实例。失效本身不删除或重建持久化索引。
7. 关闭项目时先关闭检索和索引服务，再关闭共享客户端。隐藏侧栏不销毁项目级服务。

### 文件与验证

- `settings/RagSettings.java`、`settings/RagCredentials.java`、`settings/RagSettingsConfigurable.java`、设置树分组类 `CourseAiSettingsGroup.java`
- `application/ProjectRagService.java`，以及必要的可独立测试的资源组装类。
- `META-INF/plugin.xml`：注册项目设置；`build.gradle.kts`：重新启用设置搜索索引。
- 新增有行为意义的配置/资源生命周期检查，运行现有 RAG、UI 回归和插件构建/结构检查；记录实际结果和环境。

### 用户验收

- [ ] 能从项目 Settings 打开 Course RAG，保存基础与高级参数，再次打开参数保留。
- [ ] 重开项目后参数仍保留；不同项目参数和密钥互相隔离。
- [ ] 不填写密钥也能保存未就绪配置；保存不发出网络请求。
- [ ] 密钥留空保留、替换和清除行为明确；项目普通状态中没有密钥。
- [ ] 非法地址、超时、分块/重叠、阈值或预算阻止保存并给出提示。
- [ ] 原聊天及选中代码入口继续可用且明确为 Sample。

## 3. R2：课程资料管理与索引任务

前置条件：R1 经用户验收通过。

### 工作

1. 保留现有聊天页，新增课程资料页签及设置入口；支持原生 PDF/PPTX 多选。
2. 展示登记的文件名、原始路径、可用性；支持重复登记和移除登记。移除不删除原文件，也不立即从旧索引移除内容。
3. 由 RAG 层补充只读取登记路径的管理接口，不复用会读取原文件、计算哈希并遇缺失文件整体失败的 `listDocuments()`，不让 UI 自行解析 JSON。
4. 添加资料与重建索引分开。导入完成或移除后提示待重建；重建为全量操作，会调用在线 Embedding。
5. 执行 `rebuild()` 后显式 `reload()`；只有刷新成功才显示当前可用。区分重建失败与索引已发布但刷新失败，保留可恢复操作。
6. 后台文件与网络工作，EDT 更新界面；互斥登记/移除/重建操作，提供取消。首版使用不确定进度，不编造百分比或耗时。
7. 显示未配置、未建库、构建中、可用、资料有变更和操作失败；发布前失败/取消保留旧索引；若取消发生在原子发布之后，不承诺撤回新快照，应重新读取实际状态。区分登记清单与已发布快照，重启后保守处理同步状态；不自动重建。
8. 操作复合 future 显式传播取消到当前子任务；保存设置或关闭项目后禁止旧任务更新新状态。建库使用独立生命周期，不沿用聊天 30 秒总时限。

### 文件与验证

- `ui/KnowledgeBasePanel.java`、Tool Window 组装与页签适配。
- 扩展 `ProjectRagService` 提供管理任务与安全状态；对 `DocumentImporter` 增加最小管理 API 及行为测试，保留原接口。
- 测试重复文件、同名不同路径、部分登记成功、丢失文件、取消/重复点击、重建失败保留旧索引、刷新失败、设置切换及项目释放。

### 用户验收

- [ ] 无 API Key 时可登记、列出、移除 PDF/PPTX；原文件不被复制或删除。
- [ ] 丢失文件仍显示且可移除；重复登记不增加重复条目。
- [ ] 点击重建后界面不冻结，能取消，成功后报告文件/片段数量。
- [ ] 新建库失败保留旧库；移除但未重建时明确提示旧库仍可能含该文件。
- [ ] 重开项目后登记与索引状态可恢复；多项目互不串库。

## 4. R3：独立检索预览

前置条件：R2 经用户验收通过。

### 工作

1. 在课程资料页提供问题输入、查询/取消和结果区域，通过 `KnowledgeSearch.search(question, 5)` 调用真实检索。
2. 每条结果显示可选择复制的片段正文、原始文档名和物理 PDF 页码或 PPTX `slide N`，保留真实引用 ID。分数可作为调试信息显示，不称为置信概率。
3. 区分有命中、成功但无匹配、检索失败；未建库、损坏、模型不兼容、网络/鉴权错误不能伪装成空结果。
4. 取消、切换配置、关闭内容/项目后抑制旧回调；界面输入与主题行为沿用现有约定。
5. 模型/维度/前缀/切分改变提示重建；阈值和多步检索参数改变不要求重新 Embedding。首版不实现点击引用打开原文件，因为现有 SourceReference 没有原路径。

### 文件与验证

- 扩展 `KnowledgeBasePanel` 与 `ProjectRagService`，不把检索预览接到 ChatAnswer 或冒充真实聊天。
- 自动检查成功有命中/空列表/异常、取消与过期回调；在真实 IDEA 使用实际 PDF/PPTX 验收。
- 真实供应商联调由用户在设置中提供配置，不把本地 HTTP/可控向量测试称为真实模型验收。

### 用户验收

- [ ] 实际课件能命中预期正文和正确页码/幻灯片位置。
- [ ] 重启后能加载已建索引检索；原文件移动后旧快照仍可查。
- [ ] 无关问题显示无匹配；网络、未建库和不兼容错误分别提示，能够恢复。
- [ ] 查询可取消，旧结果不覆盖新结果；聊天继续明确为 Sample。
