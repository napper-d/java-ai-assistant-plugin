# I3：聊天展示与课程资料界面审阅

更新：2026-10-29。当前内容覆盖用户对 I3 的后续界面修订；I2 及本轮变更均保留在工作区，由用户进行 Git 提交。

## 当前界面

1. **欢迎页**：标题、副标题和三项实际能力统一居中；标题突出，副标题为较小次要文字，能力项以正文显示并使用统一间距。右上方为 Chat、清空及 Course materials 图标。切换页面保留会话、草稿与请求。
2. **思考提示**：请求期间只在消息区显示 Thinking，完整移除底部状态栏，包括 Response received、失败/取消状态；错误仍在消息区展示。发送/换行提示文字也已完全删除；Enter 发送、Shift+Enter 换行的行为保留。
3. **Markdown 回答**：CommonMark 0.30.0 将 AST 转为 Swing StyledDocument，支持标题、粗体/斜体、列表、引用、行内/围栏代码及链接文本；另通过同版本 commonmark-ext-gfm-tables 支持 GFM 表格。表头加粗并使用底色、网格边框适配主题，单元格保留行内样式与列对齐，窄窗口按列换行。代码使用等宽字体与底色。HTML 按字面文本显示，图片只显示替代文字，不执行脚本、不自动请求外部资源；这不是嵌入浏览器。
4. **回答和引用卡片**：分别使用有内边距的边框卡片。边框读取 `JBColor.namedColor("Component.borderColor", fallback)`，跟随 IDE 主题；资料页和表格也在主题更新时刷新配色。没有更换全局主题或编辑器配色。
5. **编号与证据**：每个回答的来源按正文首次出现顺序从 1 编号，重复引用复用编号。默认只显示编号、文件名和页码/slide；点击展开本次实际使用的原文、片段 ID 和检索分数。内部引用 ID 继续用于服务校验，向量数组不在界面展示。详情来自不可变回答快照，不重新检索或调用模型。
6. **资料列表**：文件名为主体，每行右端是垃圾桶；加号添加 PDF/PPTX，右上方齿轮打开 Course RAG 设置。没有路径/状态列、常驻 Update materials 或底部说明。路径仍在悬停提示中提供，用于区分同名文件。
7. **导入进度**：登记成功立即显示文件名，后台继续自动索引。顶部仅在加载/索引期间显示进度条和取消图标，不编造百分比。失败时在顶部显示短状态，悬停查看完整安全说明，并按需显示重试图标。

此前的 Update materials 用来重新读取已修改原文件和重试索引，而非保留文件的必要条件。现在已移除；要更新原文件内容，可再次通过加号选择同一文件。

主题方案参考 [IntelliJ UI FAQ](https://plugins.jetbrains.com/docs/intellij/ui-faq.html)；解析器参考 [CommonMark Java](https://github.com/commonmark/commonmark-java)。

## 后台与范围

- 添加和删除仍通过 MaterialUpdateTask 串联登记/移除与索引阶段，取消传到当前子任务；原文件不会被删除。
- 设置保存本身不调用 API。配置缺失时资料保留登记，顶部提示配置后重试；部分导入失败后重新读取实际清单并保留原始安全错误。
- 索引失败/取消可保留磁盘旧快照，但 Chat 检查登记清单、空库及待更新状态，不把不一致快照作为当前资料。删除最后一份文件及重新加载后也不会回答旧内容。
- 独立检索页面及专属 UI 代码已删除，后端检索用例保留为 CourseRetrievalIntegrationTest。没有恢复该页面。
- 仅本次问题、显式选区和课程证据进入模型；Markdown 渲染不改变模型请求，不自动读全工程或写源码。
- 打开原文件对应页仍暂缓：引用契约没有可靠原路径，同名文件不能按名称猜测。F2 统一设置接线仍为 I4 工作。

## 用户验收

1. 重启开发 IDEA，检查欢迎页居中对齐及右上图标。输入草稿切换资料页后返回，内容保留。
2. 在已配置项目中提问，等待期间只看见消息区 Thinking；要求回答包含标题、列表、粗体、代码块和 GFM 表格，检查格式、边框及复制行为。
3. 检查每条回答的编号从 1 开始，来源名称/页码可读，点击展开相应原文且不触发额外模型请求。
4. 资料页只显示文件名和行末垃圾桶；通过加号添加后观察右上进度条和即时文件名。删除不影响原文件；齿轮打开设置。
5. 检查取消、错误 Key、部分文件导入失败和配置切换后可恢复，没有过期内容回填；移除最后一份材料后 Chat 不继续引用旧资料。
6. 明暗主题切换和窄窗口下检查回答、来源卡片、文件名和图标的对比度。真实供应商及实际 IDEA 由用户验收。
