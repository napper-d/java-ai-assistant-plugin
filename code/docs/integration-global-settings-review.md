# IDE 全局配置与课程库

日期：2026-10-29。用户要求新项目直接使用已有模型和课程库，并允许首次重新配置；因此不实现自动迁移，不触碰旧项目配置、密钥或 .course-ai 数据。

- GlobalConfiguration 是应用级持久化服务，普通参数保存到 IDE 配置目录的 options/course-ai-assistant.xml；设置入口改为 applicationConfigurable，两个页面明确显示共享范围。
- LLM / Embedding 密钥分别保存到 Password Safe 的两个全局命名空间，保留留空不替换、替换、清除的原有行为。不显示密钥，不将其写入 XML。
- 课程资料清单及索引存于 IDE 配置目录下 course-ai-assistant/.course-ai，所有项目通过 GlobalRagLibrary 共用同一套资料管理、Embedding 客户端和索引快照。原课件仍保留原路径。
- ProjectRagService 作为项目借用入口只跟踪和取消自己的请求，关闭项目不关闭应用级课程库；修改全局 RAG 配置会让所有项目的聊天请求失效。
- Chat / F2 模型会话仍由各项目管理，读取同一份全局连接配置。修改全局模型配置广播到所有打开项目，取消生成和旧审阅；F2 最终写回核对全局配置版本，避免跨项目配置变化后应用旧建议。
- 资料变更通知用于刷新其他窗口中的文件列表；普通列表刷新不产生新的变更广播。课程管理操作仍串行执行，操作繁忙时需要等待后重试。
- 旧 LlmSettings / RagSettings 项目状态仅为兼容保留，生产设置和请求读取全局参数；不自动读取或迁移旧项目密钥、资料和索引。

## 验证与手动检查

复用现有测试 **135 项通过，0 失败、0 错误、0 跳过**（最终版本 45s）。没有新增测试；将原有“不同项目的模型密钥命名空间不同”断言改为“不同项目共用全局命名空间”。这些回归覆盖旧接口、取消及检索基础行为，不等同于多窗口真实 IDE 验收。本轮未重打安装包或运行搜索索引辅助 IDE。

1. 重启开发 IDE，配置 Language model 和 Course RAG 两套连接/Key，重新添加一次 PDF/PPTX 并等待索引完成。
2. 新建或打开项目 B：连接参数和资料列表应相同，不需再次配置或导入即可提问。
3. 同时打开 A/B，添加或删除资料后检查另一窗口列表；关闭 A 后在 B 继续提问。
4. 修改全局模型配置，检查其他项目的旧生成/待批准建议不能应用；重启 IDE 后检查设置与资料仍保留。
